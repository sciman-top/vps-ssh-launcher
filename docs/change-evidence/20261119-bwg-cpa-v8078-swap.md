## 项目代码修复（同提交 `beaba03`）

`vps_ssh_launcher/connection.py` `connect_with_retry` 此前只捕 `OSError`：Paramiko
把预认证阶段断连（服务端 MaxStartups 丢新连接、SOCKS5 中继抖动）包装成
`SSHException("Error reading SSH protocol banner…")` 或 `"No existing session"`
抛出，>12k 字符的分块传输（每块一次新 SSH 会话）一遇即整体失败——这是前一会话
`cpa_bwg_guardrails.ps1` / `proxy_hardening_drift.ps1` 反复中断、任务停摆的根因。
现按消息白名单（`error reading ssh protocol banner` / `no existing session`）重试
瞬态握手失败与裸 `EOFError`；`AuthenticationException`/`HostKeyException` 子类与
未知 `SSHException` 消息保持终局不重试（重试永远不能掩盖错密钥/不受信任主机键），
客户端测试替身缺异常族时保持旧 no-retry 行为。测试：`tests/test_connection.py` +
`tests/launcher_fakes.py` 新增 8 项（63 passed / 1 platform skip）。
