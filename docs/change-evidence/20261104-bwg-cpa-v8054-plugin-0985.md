# BWG CPA v8.0.54 + WorkBuddy 0.9.85 联合升级（2026-11-04）

## 目标与边界

用户要求直接更新 BWG 的 CPA 与插件，并同时防范 OpenAI/GPT、
Antigravity/Gemini、WorkBuddy CN/INTL、Claude/Anthropic 的封号、限流、
降智、慢吐字与缓存风险。本次只变更 BWG：

- 没有新增、删除、轮换、隔离或导出 OAuth/API-key 凭据。
- 没有提高并发、RPM、重试或清除 cooldown。
- 没有发送 OAuth 生成探针；升级验收使用隔离 fixture、readiness 和升级后自然流量。
- Claude 保持惰性退役墓碑；slot 3 明文 HTTP API key 继续保持既有告警。
