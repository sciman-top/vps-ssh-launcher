# 双 GLM 交接、审批和状态台账

## 统一契约

每份报告使用 HG-03 Integration v4.1、角色、Git HEAD/branch、时间和时区、执行环境、实际主机别名（不要在公共 Git 放真实 IP/内网）、审批号、证据定位、下一动作。HOME 是服务端唯一写入者；OFFICE 仅本机。脱敏报告经批准渠道手工转交，Git 不作为实时依赖；必要同步提供 commit/hash、补丁。未确认的参数写 UNKNOWN；不能实施写 BLOCKED；未测试写 NOT_RUN；UNVERIFIED 不是 PASS。真实凭据单独安全交付，不随报告。对端报告不能当自动授权。报告若使用 `hg03_contract.py`，记录 `HG03_CONTRACT=PASS` 和 schema 版本；它仅证明证据结构符合合同，不证明远端业务。
