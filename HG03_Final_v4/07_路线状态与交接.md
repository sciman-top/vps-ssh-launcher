## 2. H 路线服务端定案：路由器 WireGuard（淘汰"电脑承载"与一切穿透插件）

- 宿主=家庭华硕路由器（WiFi7 机型，固件原生 WG 服务器，已确认存在该功能页）；不依赖任何常驻电脑，ONOFFICE 承载讨论随之搁置（宽带路线失败才重启）。
- **穿透类插件/固件全部否决**：官方 stock 无内网穿透功能；第三方固件不覆盖中国区 SKU；frp 需公网中转（撞阿里红线或境外不可达）；Tailscale/ZeroTier 协调服务器在境外（单位封外网下不可达）。WG 零协调、单一 UDP 端口，是唯一适配形态。
- 客户端配置纪律：AllowedIPs 只放 BWG 地址/32（拆分隧道，保单位内网零影响）；每 peer 独立密钥可撤销；PersistentKeepalive=25；MTU 1412（PPPoE 外层）；"访问内部网络"默认关。
- 服务端纪律：PPTP/OpenVPN/IPSec 服务器全部关闭（PPTP 认证已破），只留 WG；管理面绝不出 WAN。
- DDNS 三路径：①路由器自带 asuscomm（起步推荐）②阿里云解析 API 脚本（中性子域）③裸 IP 手动。先用裸 IP 验证握手，再切 ①。
- IPv6 备胎：路由器 WAN IPv6 开启（Native）；若运营商给 CGNAT 则 v6 是唯一自然入站路径。

## 2.5 H-frp 备胎分支（2026-11-13 建成，HOME 侧已验证）

- 拓扑：OFFICE v2rayN → ECS 中继端口（TLS+token 的 frp 隧道）→ home 落地 → BWG 既有 REALITY 入口 → 境外。**ECS 只承载国内腿，跨境腿走家庭线（既有状态）**——阿里云"流量穿透"条款的合规边界即在此：不得把中继扩为 ECS 直连境外目的地的流量搬运。
- OFFICE 侧接入（判据③通过 + 单位口径允许后）：复制现有 BWG REALITY 节点，**只改地址=中继主机、端口=中继端口**（uuid/flow/SNI/pbk/sid/fingerprint 一字不动；REALITY 认证发生在 BWG 侧）。建议另存新别名，原节点保留回退。
- 覆盖范围：仅被映射的那一条 TCP 目的地（私下交付）。其余节点（其它端口/其它 VPS/UDP 类）不经此路；需要时按"第二条腿"扩容流程另批。
- 生命周期：frps=ECS systemd 常驻；frpc=home PC 登录自启（隐藏窗口），**PC 睡眠/关机即断**——白天使用时 home PC 须在线。长期形态（ONOFFICE/路由器 Entware/回归 WG）另行决策。
- T1 验收：判据③通过后，v2rayN 实测延迟 + 打开一个境外页 = 该链路 live_accepted；并把测试经过记入 T1-RESULT。

## 3. 新宽带装维三要求（照提）

1. 光猫改桥接，自用路由器 PPPoE 拨号（或索取光猫超级密码）；
2. 要动态公网 IPv4，确认 WAN 非 100.64/100.65 段（CGNAT 判定）；
3. 光猫 LAN 直连路由器 WAN，不留中间设备（现网实测共享线存在三层 NAT 与一台不明中间设备）。

装好当天顺序：确认公网 → 开 DDNS/建解析 → WG 服务端按 §2 配置 → 手机流量外测握手 → 晚高峰实测上行 → 才进 T1-H。

## 4. T1 通用判据（OFFICE 现场，一分钟级）

```text
① TCP: Test-NetConnection <C-ENTRY-HOST> -Port 443        # C 路线生死（<C-ENTRY-HOST> 私下交付）
② TCP: Test-NetConnection <C-ENTRY-HOST> -Port <H-RELAY>   # H-frp 备胎生死（同一中继主机，<H-RELAY> 端口私下交付）
③ UDP: nslookup qq.com 223.5.5.5                            # WG 路线生死（任意国内 UDP 出站是否存在）
```
- ①通 → 备案通过后 C 即插即用；①不通 → API 走 E（IT 加白），如实 BLOCKED。
- ②通 + 单位口径允许 → **当天即可按 §2.5 两字段接入，境外网页当日恢复**（不依赖新宽带）。
- ③通 → 新宽带到位后 WG 直连形态可进；③不通 → WG 在单位有线不可用（网页只能走 ②或 E/热点）。
